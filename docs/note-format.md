# Формат конспекта

Все конспекты на сайте собираются по одной схеме, чтобы читались одинаково и
чтобы под них одинаково писались квизы. Файл конспекта — MDX с шапкой:

```mdx
---
subject: matematicheskiy-analiz
number: 3
title: Лекция 3. Предел последовательности
summary: Определение предела, единственность, ограниченность сходящейся последовательности, арифметика пределов.
lectureDate: 2026-09-18
status: published
---
Вводный абзац: о чём занятие и зачем это нужно дальше по курсу.
```

Поля шапки совпадают с `NoteInput` из `lib/api/types.ts`; `subject` — слаг
предмета. `slug` не указывается: сервер строит его из названия, а
`scripts/content.ts` дописывает его в шапку после первой публикации, чтобы
повторный `push` обновлял конспект, а не создавал новый.

## Название и аннотация

- Лекция: `Лекция N. Тема`. Практика: `Практика N. Тема`. Разовое занятие
  без номера: `Семинар 7 сентября: тема`.
- `summary` — одно предложение до 200 символов: перечисление тем через
  запятую, без «в этой лекции рассматривается».
- `number` — порядковый номер конспекта внутри предмета (лаб это не касается).

## Скелет

```
Вводный абзац (2–4 предложения)
<Callout type="tip">                          — необязательно: главный приём / как читать
## 1. Тема
### 1.1. Подтема
## 2. Тема
…
## Частые ошибки                              — теория; для оргзанятий: «На что обратить внимание»
## Мини-тренажёр + <Spoiler title="Ответы">   — теория; для оргзанятий: «Чек-лист»
## Шпаргалка                                  — всегда, таблица «Понятие | Суть»
```

- Основные разделы нумеруются `## N. …`, подразделы `### N.M. …`, порядок —
  как на занятии. Три финальных раздела без номеров.
- Заголовки — только текст: без формул, эмодзи и бэктиков (формулы в
  заголовках ломают оглавление).
- Разделов «Источники», «Литература», «Примечания к записи» нет. Что не
  удалось подтвердить по записи, в конспект не попадает и сообщается
  отдельно.

## Оформление внутри разделов

- `**Определение N.**`, `**Теорема N.**`, `**Утверждение N.**` — сквозная
  нумерация внутри конспекта. Доказательство: `*Доказательство.* … $\blacksquare$`.
- Математика только в `$…$` и `$$…$$` (KaTeX), никаких формул в бэктиках или
  юникодом в тексте. Множества `\mathbb R`, отображения `f\colon X\to Y`.
- Ключевые ловушки — `<Callout type="warning">`, важные факты — `type="danger"`,
  примеры и замечания — `type="info"`, приёмы — `type="tip"`. Не больше одного
  коллаута на экран.
- Организационное (баллы, дедлайны, штрафы) — таблицей, полностью, это то,
  ради чего конспект открывают.
- Команды и код — в fenced-блоках с языком и `title="file"`, где уместно.
- Ссылки на другие конспекты — относительные: `/notes/<subject>/<slug>`.
- Картинки и файлы (схема с доски, методичка) — относительным путём от
  `.mdx`: `![Схема с доски](./img/board.jpg)`, `[Методичка](./metodichka.pdf)`.
  `note push` заливает их в хранилище сайта и отправляет текст с адресами
  `/api/v1/files/…`; локальный файл не меняется, повторный push переиспользует
  уже залитое. Подпись картинки — что на ней, а не имя файла. Отдельно залить
  файл и получить разметку: `bun scripts/content.ts file push <файл>`.
- Одна мысль на абзац или пункт списка. Без «лектор сказал, что» в каждом
  пункте; яркие цитаты — короткие и в кавычках.
- Объём: теория 15–40 КБ, оргзанятие 5–10 КБ.

## Факты

- Из аудиозаписи в конспект попадает только то, что подтверждено записью
  (правила сверки — в скилле `konspekt` проекта lecture-transcriber).
- Из бумажного конспекта восстанавливать пропущенные шаги доказательств и
  стандартные примеры можно, но каждое число, формулу и контрпример нужно
  пересчитать.
- Обозначения согласуются с уже опубликованными конспектами предмета.

## Проверка

```bash
bun scripts/content.ts mdx check file.mdx   # компиляция тем же пайплайном, что и сайт
bun scripts/content.ts note push file.mdx   # проверяет и публикует
```

Квиз к конспекту — по [quiz-format.md](quiz-format.md): 12–24 вопроса, смесь
`single`/`multiple`/`text`, у каждого вопроса `explanation` и `tags` по
названиям разделов, проверяется понимание, а не запоминание номеров.
