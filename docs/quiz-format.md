# Формат квизов

Квиз хранится в базе как JSON-массив вопросов (поле `questions`). В админке его
можно собрать в конструкторе или вставить готовый JSON во вкладке «Импорт JSON».
Этот же формат используется, когда квиз пишется по конспекту.

```json
{
  "title": "Лекция 3. Указатели",
  "description": "Быстрая проверка после лекции",
  "subjectSlug": "programmirovanie",
  "noteSlug": "lektsiya-3-ukazateli",
  "questions": [
    {
      "id": "q1",
      "type": "single",
      "prompt": "Что возвращает `sizeof(int*)` на 64-битной системе?",
      "options": [
        { "id": "a", "text": "4 байта", "correct": false },
        { "id": "b", "text": "8 байт", "correct": true },
        { "id": "c", "text": "Зависит от значения указателя", "correct": false }
      ],
      "explanation": "Размер указателя определяется разрядностью адреса, а не типом данных.",
      "points": 1,
      "tags": ["указатели"]
    },
    {
      "id": "q2",
      "type": "multiple",
      "prompt": "Какие операции допустимы над указателями?",
      "options": [
        { "id": "a", "text": "Сложение с целым числом", "correct": true },
        { "id": "b", "text": "Вычитание двух указателей одного типа", "correct": true },
        { "id": "c", "text": "Умножение двух указателей", "correct": false }
      ],
      "explanation": "Арифметика указателей ограничена сдвигом и разностью."
    },
    {
      "id": "q3",
      "type": "text",
      "prompt": "Как называется указатель, который никуда не указывает?",
      "answers": ["нулевой", "нулевой указатель", "null", "nullptr"],
      "explanation": "Любой из вариантов засчитывается. Регистр, пробелы и ё/е не важны."
    }
  ]
}
```

## Правила

| Поле          | Обязательно | Описание |
| ------------- | ----------- | -------- |
| `id`          | нет         | Уникальный в пределах квиза. Если пропущен, будет `q1`, `q2`, … |
| `type`        | да          | `single` — один верный вариант, `multiple` — несколько, `text` — свободный ввод |
| `prompt`      | да          | Текст вопроса. Поддерживается Markdown: `**жирный**`, `` `код` ``, формулы `$x^2$` |
| `options`     | для single/multiple | Минимум два. У `single` ровно один `correct: true`, у `multiple` — хотя бы один |
| `answers`     | для text    | Список принимаемых ответов. Сравнение без учёта регистра, лишних пробелов и ё/е |
| `explanation` | нет         | Показывается после ответа. Markdown |
| `points`      | нет         | Вес вопроса, по умолчанию 1 |
| `tags`        | нет         | Темы для группировки |

Поля `title`, `description`, `subjectSlug`, `noteSlug` вне массива — подсказки
для админки; сам API принимает `subjectId`/`noteId`, которые выбираются в форме.

Квиз с `shuffleQuestions: true` перемешивает вопросы, с `shuffleOptions: true` —
варианты. Результаты прохождения хранятся только в браузере пользователя.
